把创作组织成工作流

FrameWeave 将工作台、画布、队列、作品管理与 Worker 放在同一条创作链路中。关注的不只是生成动作，也包括任务与结果如何被组织。

让协作进入开发过程

ClaudeBrainDuel 以 Claude Code CLI 为基础，探索双脑协作开发。实现与使用方式以项目仓库中的说明为准。

从页面到讲稿

PPTX-TO-SPEECH 把逐页内容整理为可编辑的讲稿，并支持将讲稿写入 PPTX 备注。以 TypeScript 和 React 构建。
